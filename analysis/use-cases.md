# Use cases

## UC-01 — Привязать QR к сессии

Актор: авторизованный мастер. Предусловие: устройство создано.

1. Мастер выбирает устройство.
2. Указывает состав, крепость, при необходимости стол и описание.
3. Подтверждает форму.
4. Система деактивирует прежние активные сессии, создаёт новую с pending-флагом и публикует событие.
5. Гость по той же QR-метке получает новую активную сессию.

Альтернативы: отсутствует обязательное поле — 400; нет авторизации — 401. Конкурентное создание требует отдельной проверки.

Критерий: Given метка D с активной сессией S1, When мастер создаёт S2, Then последующий запрос по D показывает S2, а S1 неактивна.

## UC-02 — Позвать мастера

Акторы: гость и мастер. Предусловие: гостю показана активная сессия.

1. Гость нажимает вызов.
2. Система сохраняет флаг запроса и публикует событие.
3. Панель мастера получает событие, проигрывает звук, перечитывает данные.
4. Мастер открывает карточку и снимает флаг.

При отсутствии связи целевое поведение — сообщить о недоставке и предложить повтор; требует проверки. Снятие флага при открытии не равно фактическому обслуживанию гостя.

## UC-03 — Запросить рецепт

1. Гость запрашивает рецепт, если он ещё не доступен.
2. Система устанавливает mixRequested и публикует событие.
3. Мастер формирует рецепт и сохраняет его, снимая флаг запроса.
4. Система публикует recipe_ready.
5. Гостевой экран перечитывает сессию и показывает рецепт.

Альтернативы: рецепт уже существует — показать сразу; состав изменился — прежний рецепт сброшен в сценарии редактирования; соединение прервано — проверить восстановление.

Критерий: Given активная сессия без рецепта, When мастер сохраняет рецепт после запроса, Then гость может открыть его без ручного обновления при доступном SSE.

## UC-04 — Голосовое заполнение

1. Мастер записывает голосовую команду.
2. Система отправляет аудио на транскрибацию.
3. Текст структурируется LLM с опорой на справочник.
4. Результат заполняет форму.
5. Мастер проверяет, исправляет и подтверждает данные.

Альтернативы: слишком большой файл, неизвестный ингредиент, ошибка AI — ручное заполнение. Не сохранять AI-результат без подтверждения формы.

## UC-05 — Просмотреть аналитику

Управленческий сценарий: открытие панели и просмотр сумм обращений за текущие день, неделю и месяц, а также графиков. Интерпретировать показатели как обращения, не уникальных посетителей.

## User stories

- US-01: как мастер хочу повторно использовать метку, чтобы не печатать новую для каждого заказа.
- US-02: как гость хочу узнать состав по QR, чтобы не уточнять его у сотрудника.
- US-03: как гость хочу позвать мастера, чтобы сообщить о потребности.
- US-04: как мастер хочу заполнить форму голосом, чтобы уменьшить ручной ввод (гипотеза эффекта).
