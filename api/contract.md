# Интеграции и API

[К кейсу](../README.md)

Публичная выборка; не полный каталог рабочих endpoints. Адрес развёрнутого сервиса исключён. Контракты восстановлены статически, не проверены HTTP-запусками.

| Метод / путь | Назначение |
|---|---|
| POST /api/sessions | Создание сессии мастером |
| GET /api/devices/{id}/active | Получение текущей сессии и фиксация обращения |
| PUT /api/sessions/{id} | Изменение сессии и запросы гостя |
| GET /api/events | SSE |
| POST /api/ai/transcribe | Аудио → текст |
| POST /api/ai/parse-session | Текст → структура формы |

[OpenAPI — выборка](openapi.yaml)

## Событийный контракт

| Событие | Назначение |
|---|---|
| session_created | Изменение доступности сессии, перечитывание панели |
| master_called | Запрос мастера |
| mix_requested | Запрос рецепта |
| recipe_ready | Готовность рецепта |

Бизнес-события содержат type, deviceId, sessionId. При подключении передаётся connected; heartbeat примерно каждые 25 секунд. SSE не является подтверждением фактического обслуживания. Для надёжной продуктовой аналитики нужны отдельные timestamps и идентификаторы запросов.
